## 1. 프롬프트 항목별 번역표

레퍼런스 프롬프트는 보통 아래 항목으로 나뉜다. 항목마다 "무엇을 코드로 하는가"를 먼저 정하고 시작한다.

| 프롬프트 항목 | 코드에서 하는 일 | 템플릿 위치 |
|---|---|---|
| Style reference (시대·매체) | 화면비(4:3/16:9), 필름 처리 강도, 팔레트 | `W,H`, `film()` |
| Scene (사건 순서) | 컷 목록과 시간표 (`SHOTS`) | ⑤ |
| Character / The robot / The streetcar | 셀 그리기 함수 + 상태 함수(시간→램프·자세) | ③ |
| Linework | `ink()` 굵기·떨림·색 홀드 선 | ① |
| Coloring | 단색 면 + 그림자 1~2단 `fill()`, 하이라이트 `glow()` | ③ |
| Backgrounds | `layer()` + `paint()` 미리 칠하기, 시차 계수 | ② |
| Lighting | 광원별 `glow`(lighter) + 젖은 면 반사 + 홀드 선 색 | ③④ |
| Effects | 손그림 획 효과 (`rain`, `sparkBurst`, `trail`) | ④ |
| Animation | on twos(`DS`, `tc=floor(t*12)/12`), 단계별 홀드 | 전체 |
| Direction (샷 목록) | 카메라 `camLerp`, 컷 길이, 하모니 프레임 | ⑤ |
| Do not let it look like | 점검 체크리스트 (10절) | — |
| Sound | Web Audio `nz/osc/bell/pad` 시간표 | ⑦ |

## 2. 셀(캐릭터) 그리는 법

- **면:** 기본색 1개 + 그림자 1단(조금 어둡게) + 그림자 2단(가장 어둡게, 좁게). 그라데이션 없이 딱 떨어지게 `fill()`.
- **선:** 바깥 실루엣 `w≈3~3.5`, 안쪽 디테일 `w≈1~1.6`. `ink()`가 구간마다 굵기를 바꾸고 `DS`마다 떨게 함.
- **색 홀드 선:** 빛을 받는 가장자리 위에 얇은 색 선을 한 번 더. 따뜻한 빛 = `#ff9a44`, 젖은 면·하늘 반사 = `#62d6ec`, 차가운 그림자 = 푸른 회색.
- **하이라이트:** 금속·유리에만 `glow()`를 약하게(알파 .2 안팎). 캐릭터 전체에 에어브러시 금지(레퍼런스가 금지하는 경우가 많음).
- **낡음 표현:** 리벳 아래로 흐르는 녹물 획, 벗겨진 페인트 얼룩(밑칠 색), 이음매의 이끼 획, 금 간 유리 곡선.
- **복잡한 캐릭터는 미리 그리기:** 움직이지 않는 몸체를 선 떨림 3종으로 오프스크린 캔버스(해상도 2배)에 그려 두고 `CARV[DS%3]`처럼 번갈아 쓴다. 움직이는 부분(바퀴·팔·눈·램프)만 매 프레임 그린다.
- **기준점 변환:** 캐릭터를 경로 위에 올릴 때 `translate(기준점) → rotate → translate(-로컬 기준점)`. 기울기는 반드시 한계를 둔다(10절).
- **얼굴 없는 캐릭터의 감정:** 램프 밝기, 고개(부품) 들기, 몸 기울기·출렁임으로만 표현한다.

## 3. 배경 칠하는 법

- `layer(x0,x1,y0,y1,해상도배율,fn)`으로 **시작할 때 한 번만** 칠한다. 매 프레임 `paint()`를 부르면 느려진다.
- **포스터컬러 느낌:** `paint()`의 붓질 방향 `a`(하늘·바다는 가로 0, 벽은 세로 π/2), 획 길이 `l0~l1`, 알파 `.1~.4`, 색 흔들림 `v .03~.06`.
- **종이 질감:** `layer()`가 마지막에 `paper()`를 자동으로 덮는다.
- **반복 금지:** 집·나무·바위는 반복문 안에서 `rnd()`로 폭·높이·지붕 모양을 매번 바꾼다. 같은 함수를 같은 값으로 두 번 부르지 않는다.
- **시차:** 하늘 `.2`, 먼 산·마을 `.5`, 중경 건물 `.8`, 근경 `1`. 시차 때문에 레이어가 밀리므로 화면보다 300~700px 넓게 칠한다.
- **글자 금지:** 간판·번호판은 읽을 수 없는 붓 모양(작은 `blob` 몇 개)으로만. 상표·로고 금지.
- **화면 밖 확인:** 카메라가 가장 멀리·높이 갈 때 레이어 끝이 보이지 않는지 스틸로 확인한다.

## 4. 빛과 반사

- 광원은 `globalCompositeOperation='lighter'` + `glow()` 두 겹(큰 은은한 것 + 작은 진한 심지).
- **깜빡임:** `hash(Math.floor(t*12))`로 일정 확률로 밝기를 떨어뜨린다(프레임마다 같은 결과 → 점검 가능).
- **젖은 바닥:** 광원 아래에 세로로 긴 반사 획을 **가늘고 투명하게 많이**(알파 .08~.35, 굵기 1~3.5, 90획). 굵은 획 몇 개는 막대처럼 보인다.
- **물웅덩이:** 장면을 다 그린 뒤 웅덩이 윗선 기준으로 화면을 뒤집어 2px 줄씩 좌우로 살짝 흔들어 붙이고 타원으로 잘라 어둡게 덮는다. 흐림은 복사본에 **한 번만** 건다.
- **빛 원뿔(전조등·탐조등):** 시작점에서 퍼지는 사다리꼴 + 선형 그라데이션(lighter). 원뿔 안 빗줄기는 더 밝게.
- **번개:** 흰 프레임 2장 → 하모니 프레임(장면을 실루엣으로 만들고 연한 하늘색으로 덮은 정지 화면, 1초 안팎) → 원래 화면.

## 5. 효과

- 전부 **손으로 그은 획**으로. 동그란 점 파티클을 대량으로 뿌리면 "파티클 시스템" 느낌이 난다.
- **비:** 먼 비(가늘고 짧게) + 가까운 비(굵고 길게) 두 층, 위치는 `hash(i, DS)` → on twos로 다시 그려짐. 땅에는 작은 왕관 모양 튀김.
- **눈:** 비와 같은 구조로, 획 대신 작은 불규칙 다각형 + 바람 방향 기울기. 돌풍은 반투명 붓질 띠.
- **불꽃:** 꺾인 짧은 선 몇 개 + 작은 `glow`. 꼬리는 `trail(posAt,t)`처럼 **과거 시점 위치를 다시 계산**해서 그린다(상태 저장 없음 → 어느 시점이든 같은 그림).
- **구름:** 둥근 덩어리(`ar` 원 + 약간의 요철)를 겹치고, 빛 쪽 테두리는 덩어리를 빛 반대 방향으로 **10~20px만** 밀어 칠해서 남긴다. 더 밀면 금 간 것처럼 보인다. 테두리 안쪽에 약한 `glow`를 더하면 부드러워진다.
- **흩어지는 조각(녹·눈덩이):** 정해진 시각마다 `hash`로 방향·속도를 정하고 포물선으로 떨어뜨린다.

## 6. 움직임과 타이밍

- **on twos:** 캐릭터 상태는 `tc=Math.floor(t*12)/12`로 계산한다(12fps). 카메라 이동만 24fps로 부드럽게.
- **무거운 것:** 단계 사이에 멈춤(hold)을 둔다. 예) 집전장치: 0.6초 들림 → 0.5초 멈춤 → 0.4초 들림 → 멈춤.
- **가벼운 것(새·고양이):** 빠르고 짧게, 스미어(늘어난 모양) 1장 + 속도선 2~3개.
- **겹치는 움직임:** 매달린 것(손잡이·호스·깃털·덩굴)은 본체보다 늦게, `sin(tc*속도+위상)`으로 흔들고 충격 때 진폭을 키운다.
- **가속:** `거리 = ½·a·(t-t0)²`. 정지 상태에서 "속도를 붙여" 출발하는 느낌.
- **음과 동기화:** 화면 시계를 `AC.currentTime - t0`로 쓰면 소리와 그림이 어긋나지 않는다.

## 7. 필름 질감 값 (템플릿 `film()` 기본값)

| 요소 | 값 | 바꿀 때 |
|---|---|---|
| 게이트 흔들림 | ±0.8px | 더 낡은 필름이면 ±1.5 |
| 전사 흐림 | blur .5px | 선명한 디지털 리마스터 느낌이면 0 |
| 할레이션 | 1/4 크기·contrast 2.4·blur 5px·screen .6 | 빛이 많은 장면은 .4 |
| 들뜬 검정 | screen rgb(16,14,24) | 극장판 프린트 느낌이면 (10,10,14) |
| 색 틀어짐 | soft-light 따뜻한 색 .14 | 차가운 색감이면 푸른색 |
| 그레인 | overlay .17, 8장 순환 | 비디오 느낌이면 .08 |
| 비네트·깜빡임·먼지 | .6 / .04 / 18% 확률 | — |

## 8. 소리 레시피 (모두 `nz`/`osc` 조합)

| 소리 | 레시피 |
|---|---|
| 비 | 반복 잡음 → highpass 700, 실내는 lowpass 1300으로 먹먹하게 |
| 바람·돌풍 | bandpass 300→1600 스윕, 공격 1~2초 |
| 천둥 | highpass 2200 짧게(크랙) + lowpass 1200→60, 5~6초, 리버브 |
| 금속 끼익 | sawtooth 1700→2600 + 좁은 bandpass 잡음(Q 8) |
| 전기 불꽃 | highpass 2500 잡음 30~80ms를 무작위로 수십 번 + sawtooth 100Hz 웅웅 |
| 딸깍(릴레이·기어) | bandpass 2500~3200 잡음 20ms |
| 모터 신음 | sawtooth 30→60Hz, lowpass 280, 크기를 천천히 키움 |
| 깨짐·찢어짐 | lowpass 2200 짧은 잡음 / bandpass 900→2600 0.35초 |
| 종 | 비조화 배음 [1, 2.32, 2.76, 4.1, 5.4] 감쇠 2.4초 |
| 패드 | 음마다 sawtooth 두 개(±7센트) → lowpass 900~1500, 공격 1.4초 |
| 멜로디 | triangle + 한 옥타브 위 sine 약하게, 리버브 .5 |
| 작은 동물 | triangle 640→520Hz 0.5초(고양이), sine 고음 짧게 여러 번(새) |

음량 기준: 빗소리 .2~.35, 효과음 .1~.6, 패드 .02~.03(음 하나당), 마스터 .85 + 컴프레서.

## 9. 스타일 변형

| 원하는 스타일 | 바꿀 곳 |
|---|---|
| 1990년대 OVA (기본) | 에어브러시 하이라이트 허용, 깊은 그림자, 색 홀드 선, 4:3 |
| 극장판 셀 (지브리풍 같은 "시대 전통", 특정 작품 아님) | 에어브러시 금지, 그림자 1~2단만, 따뜻한 홀드 선, 하모니 프레임 강조 |
| 수채 그림책 | 선 굵기 ↓·연한 갈색 선, `paint` 알파 ↑·획 길게, 그레인 ↓, 종이 질감 ↑ |
| 종이 공작·컷아웃 | 선 대신 그림자 오프셋(3px 아래로 어둡게), on threes(8fps) |
| 픽셀 아트 | 내부 해상도 320×240으로 그리고 `imageSmoothingEnabled=false`로 확대, 필름 대신 스캔라인 |

특정 스튜디오·작품·캐릭터를 흉내 내지 말고 "시대의 일반적인 시각 언어"로만 접근한다.

## 10. 실패 사례와 해결 (실제로 겪은 것)

| 증상 | 원인 | 해결 |
|---|---|---|
| 스틸이 전부 검은 화면 + 재생 안내만 보임 | 점검할 때 `#ui` 오버레이가 캔버스를 덮음 | 점검 스크립트에서 `#ui`를 숨김 (`check_frames.js`가 처리) |
| 한 프레임에 1~2초 걸림 | `ctx.filter`를 건 채로 수백 번 그림 | 임시 캔버스에 그린 뒤 필터를 **한 번만** 걸어 붙이기 |
| 웅덩이 반사가 느림 | 줄마다 `filter=blur` | 복사본에 한 번만 흐림, 웅덩이 폭만큼만 복사 |
| 바닥 반사가 주황 막대처럼 보임 | 굵고 진한 획 몇 개 | 가늘고 투명한 획을 많이 |
| 구름 테두리가 갈라진 금처럼 보임 | 빛 테두리를 너무 크게 밀었고 색이 진함 | 10~20px만, 색은 덜 채도, 안쪽에 약한 glow |
| 날아오를 때 차량이 세로로 섬 | 경로 기울기를 그대로 회전에 사용 | 회전 한계 `Math.max(ang,-0.38)` |
| 떠오르는 장면이 너무 짧음 | 가속이 작아 컷 끝에서야 곡선 진입 | 가속을 키우고 소리 리듬도 같은 식으로 계산 |
| 마지막 컷의 작은 캐릭터가 안 보임 | 와이드에서 크기 그대로 | 클로즈 쪽으로 배치하고 1.5~2배 |
| 달이 화면 끝에 걸림 | 카메라 중심을 장면 요소와 따로 정함 | 핵심 요소(달·캐릭터)를 넣은 채 카메라 프레이밍을 스틸로 확인 |
| 예시 문장의 이름을 바꾸면 조사가 어색 ("민지이") | 이름 뒤에 조사를 붙인 문장 | 이름이 문장 끝이나 쉼표 앞에 오게 쓰기 |
