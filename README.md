# 🎬 한음쌤의 영상 실습 도우미

**Google Flow** 하나로 캐릭터 → 스토리보드 → 씬 영상 → 완성 영상까지 따라 하는 교원 연수·수업 실습용 웹 도우미입니다.
각 단계에서 질문에 답하면 Flow와 채팅 AI에 바로 붙여 넣을 프롬프트가 만들어집니다.

## 📁 구성

| 파일 | 단계 | 내용 |
|---|---|---|
| `slides.html` | 발표 자료 | AI 영상 제작 연수 SESSION 01~05 (59장) — 영상 구조·화면 담기·완성하기·AI 원리·Flow 실습 |
| `index.html` | 홈 | 5단계 로드맵, 준비물, 안전 안내 |
| `flow.html` | 1. Flow 시작 | 첫 영상 만들기 순서, 핵심 기능 6가지, 크레딧 표, 강의 전 확인 사항 |
| `character.html` | 2. 캐릭터 | 한음쌤 캐릭터 공방 — 피동장스 대화로 기본 이미지·시트 프롬프트, @재료 등록 |
| `story.html` | 3. 스토리보드 | 8초 클립 단위 `장면 / 대사` 스토리보드 프롬프트 |
| `scenes.html` | 4. 씬 영상 | 씬별 Flow 프롬프트(재료·프레임·글 방식), 크레딧 계산, 컷 다시 쓰기 |
| `finish.html` | 5. 완성·점검 | 장면 빌더 조립, 소리·움직임 다듬기, 체크리스트, 평가 루브릭 |
| `models.html` | 모델 비교 | 영상·이미지 생성 모델 비교(2026년 11월 1일 기준, 출처 포함) |
| `assets/` | 공용 | 스타일·스크립트, 예시 캐릭터 이미지(`char-base.webp`, `char-sheet.webp`) |

## ▶️ 사용 방법

- `index.html`을 브라우저(Chrome 권장)로 엽니다.
- **GitHub Pages**: `Settings → Pages → Branch: main / (root)`를 켜면 링크로 공유할 수 있습니다.
- 서버·로그인 없이 브라우저 안에서만 동작하며, 입력 내용은 그 브라우저에만 저장됩니다.
- Flow 크레딧·모델 정보는 자주 바뀝니다. `scenes.html`의 `CREDIT` 값과 `flow.html`·`models.html` 표를 강의 전에 확인하세요.

## 🎬 발표 자료 조작법 (`slides.html`)

| 키 | 동작 |
|---|---|
| `→` `Space` `PageDown` | 다음 슬라이드 |
| `←` `PageUp` | 이전 슬라이드 |
| `O` | 전체 슬라이드 보기(세션별) · `Esc`로 닫기 |
| `F` | 전체 화면 |
| `Home` / `End` | 처음 / 마지막 |

- 주소 끝의 `#번호`로 특정 슬라이드를 바로 열 수 있습니다. (예: `slides.html#42` → 실습 시작)
- 터치 화면에서는 좌우로 밀어 넘깁니다.
