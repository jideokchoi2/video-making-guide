# 🎬 진성쌤 AI 영상 만들기 가이드

캐릭터 한 명으로 AI 영상을 만드는 과정을 **4단계**로 따라 하는 웹 가이드입니다.
각 단계에서 질문에 답하면 이미지 AI·브루(Vrew)에 바로 붙여 넣을 프롬프트가 만들어집니다.

## 📁 구성

| 파일 | 단계 | 내용 |
|---|---|---|
| `index.html` | 홈 | 전체 로드맵, 준비물, 안전 안내 |
| `character.html` | 1. 캐릭터 | 진성쌤 캐릭터 공방 — 피동장스 대화로 기본 이미지·캐릭터 시트 프롬프트 |
| `script.html` | 2. 대본 | 주제·대상·길이 → 브루용 주제/대본/이미지 프롬프트, 글자 수 계산 |
| `scenes.html` | 3. 씬 나누기 | 대본을 장면으로 나눠 씬별 이미지·영상 프롬프트, 컷 다시 쓰기 |
| `finish.html` | 4. 완성·점검 | 브루 조립 방법, 음성·자막·음악 팁, 체크리스트, 평가 루브릭 |
| `assets/` | 공용 | 스타일(`guide.css`)과 스크립트(`guide.js`) |

## ▶️ 사용 방법

- 저장소를 내려받아 `index.html`을 브라우저(Chrome 권장)로 엽니다.
- **GitHub Pages**: `Settings → Pages → Branch: main / (root)`를 켜면 링크로 공유할 수 있습니다.
- 서버나 로그인 없이 브라우저 안에서만 동작하며, 입력 내용은 그 브라우저에만 저장됩니다.
